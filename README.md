# Hotel Cancellation Prediction System

Professional Streamlit application for hotel booking cancellation analytics and prediction.

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

The app includes four pages:

- Home
- Profile
- Dashboard
- Predict

Model artifacts are stored in `model/model.pkl` and `model/feature_columns.pkl`.
Dashboard data is loaded from `data/hotel_clean.csv`.
